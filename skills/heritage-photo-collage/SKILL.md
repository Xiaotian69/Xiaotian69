# Stoneframe · 石间拼贴

以用户照片中可识别的主体作为视觉锚点，通过色块、尺度、局部回声和印刷质感建立版式。参考 [风格与 prompt 指南](references/design-guide.md)；历史成品和原片见 [作品图库](../checked-collage-panel-extractor/examples/GALLERY.md)。

## 判断本轮交付

根据用户要求进入 brief、制作、或整理已有成品模式。先查已有作品和工作副本；不要因为提供了效果图就生成更多图。用户明确“不调用 image_gen”“节省额度”“只写方案”时，只扫描、选片、做低分辨率联系表或工作副本、写 brief，按数量完成即停止。

需要生成时使用当前环境实际可用且用户授权的图像工具；工具缺失时交付可执行 prompt，不假装已制作。不能用文字 prompt 代替真实附图引用。按用户指定张数和版本数执行。

## 选片与设计

- 选清晰轮廓、独特手势或目光、真实石质风化、有节奏的佛龛或彩绘细节；同一主体多角度选更适合版式的一张。
- 每张确定一个 main anchor，明确必须保留的五官、手势、雕刻与残损。不会自动修复文物缺损或把残损佛像补成完好新像。
- 三套配色中选一套并解释：群青／朱红／金黄；群青／砂金／米白；朱红／炭黑／旧纸米白。背景用大色块，材质继续保持照片可读性。
- surreal-pop：仅一个巨型新增元素（光环、手掌或来源明确的纹样），不能堆多个抢焦点符号。
- dreamcore：从照片取 2–5 个有来源的 echo fragments，通过局部放大、灰度、轻微错位或克制重复建立回声，不用无关素材填满画面。
- 删除用户照片中的现代杂物时列出实际可见项目，如灯、栏杆、线缆、游客、标牌；不要凭空声称存在。
- 指定画幅、主体占比、色块位置、回声片段坐标和留白。方形是图库惯例，用户指定竖版或横版时遵循用户。

## 每张 brief

输出原文件名、main anchor、真实摄影保留项、选定配色与理由、唯一 giant element 或 2–5 个 echo fragments、删除项、构图与画幅，以及一段能直接用于参考图编辑的最终 prompt。prompt 同时描述材质保留、结构关系和避免项，不只列风格形容词。

## 制作和检查

原片只读，在输出目录建立工作副本。制作时检查脸部身份、手指数量、真实缺损、石刻纹理、框中片段来源与边界。AI 输出可能改写细节，标为艺术再创作，不能声称像素保真或文物修复。

已有满意联系表需要拆单张时，转交 [PanelPick · 勾选拆图](../checked-collage-panel-extractor/SKILL.md) 的确定性流程，从干净版取像素。模型重画不能当作裁切。完成本轮约定结果后停止，不自动扩展整个系列。
