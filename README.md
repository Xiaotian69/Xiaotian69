## How I work / 我的工作方式

- **先确认产品事实** — 区分已实现能力与设想，再提炼清楚的价值主张。<br>*Start with the product truth: separate what works from what is planned.*
- **交付真实界面** — 优先做可运行的流程和有代表性的产品状态。<br>*Build the real interface, not concept-only mockups.*
- **把边界也设计进去** — 隐私、密钥、本地数据、AI 回退与人工确认都是产品的一部分。<br>*Design the boundaries: privacy, credentials, local data, AI fallbacks, human confirmation.*
- **展示前先验证** — 用测试、构建、链接检查、截图与部署检查支撑每一条描述。<br>*Verify before presenting: tests, builds, link checks and deployments back the claims.*
